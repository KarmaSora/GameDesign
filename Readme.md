# How to open Unity and run the game

## Requirements

- Unity version 2022.3.62f1 (the exact version used when developing the game) or latest version
- A Computer (powerfull enough not to overheat like mine does) with Keyboard and mouse

## Starting the project

1. Clone or download the repo
2. Make sure the following folders are donwloaded:
   --Assets
   --Packages
   --ProjectSettings

3. start Unity Hub
   --If you dont have a personal token, you will get a pop up window asking if you want one. click yes and proceed
   --After you have gotten your personal token you may proceed to the next step

4. In Unity Hub, click "Add project from disk"
5. Locate the project folder(the one containing the files donwloaded)
6. Open the project through Unity Hub

## Run the Game

1. In the Project WIndow, navigate to "Assets/Scene/Prototype 4"
2. Double click on it and the game should load
3. Press the play button in unity to start the game

## Game Controls

-- W = forwards, S = backwards to move
-- Mouse: Rotate the camera and chaning the players direction
-- Mouse Left click : click to Attack
-- Mouse Right click : hold to block all damage and Defend
-- Space: Jump
-- Left Shift: Hold to sprint
